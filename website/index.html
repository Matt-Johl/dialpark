Mobile SIP Gateway for iOS.

Dialpark is a call server that extends a VoIP deployment to iPhone endpoints. It interconnects a SIP PBX with iPhones running the Dialler app and, for incoming calls, acts as the local push server for Apple’s Local Push Connectivity API.

For Asterisk, Cisco CUCM and other SIP PBXs.

Features

At a glance

On-premises Fully operational without internet access
Wake-ups Dialler App wakes from closed or background state using Apple Local Push Connectivity, on the specified Wi-Fi networks
PBX Asterisk, Cisco CUCM or another SIP PBX, with a SIP trunk or one registered line per phone
Encryption TLS signalling, SRTP audio, always encrypted between Dialler app and Dialpark server
Codecs G.722, G.711
Directory Customizable per phone or bulk deployed, set in the console or by CSV, editable on the phone
Call controls Hold, transfer, mute, speaker
Requirements iOS 17 or later with the Dialler app, a SIP PBX, and a Dialpark server reachable from the phones' Wi-Fi on the listed ports

How it works

The PBX calls the server. The server wakes the phone.

The Dialpark server sits between your PBX and the phones. It sends the wake-up when a call comes in, and provides the web console for enrolment, directories and status.

Dialpark The system: the call server and its web console, installed on a machine on your network. Licensed per phone.
Dialler The iOS app, from the App Store. Each phone is enrolled to one Dialpark server and receives its calls from it.

  1. The PBX sends the call to the Dialpark server.

  2. The server wakes Dialler through Local Push Connectivity, and iOS shows the incoming call.

  3. When answered, the app connects and the server bridges the call to the PBX.

Phones receive calls only on the Wi-Fi networks assigned to them.

Setup

Two binaries, one machine

dialpark-server handles calls and wake-ups. dialpark-admin is the web console. Both are single binaries, usually run on the same machine.

7443 TCP Wake-ups and signalling
5061 TCP SIP over TLS
8080 TCP Enrolment and directory
20000–20100 UDP Call audio 
dialpark-server \
  -trunk "sip:pbx.example:5060;transport=tcp" \
  -public-host 10.0.0.10 \
  -local-domain site \
  -http-addr 0.0.0.0:8080 \
  -tls-cert server.pem \
  -tls-key server.key \
  -admin-token-file admin-token

dialpark-admin \
  -server-ca server.pem \
  -admin-token-file admin-token \
  -password-file password

For one registered line per phone instead of a trunk, add -pbx-mode lines.

Management

One console for every phone

Add a phone Enter an extension and a label; the console shows a QR code
Enrol Install Dialler on the phone, then scan the QR code with the camera or type the code in the app. Codes are single-use and expire after 15 minutes
Configure Wi-Fi networks and directory, per phone
Replace or revoke Revoke a phone, or issue a new code for a replacement
Status Phones online, PBX line registration, calls in progress
