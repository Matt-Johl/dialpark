Ext Client Phone

How the phone is reaching this server.

  • App 1.4The Dialler app is connected. The number is the version it reported.
  • Wake onlyOnly the app's wake extension is connected; the app itself is not running. An incoming call wakes it.
  • OfflineNeither the app nor its wake extension is connected.
 SIP

The app's SIP registration with this server, which is what lets it place and take calls.

  • RegisteredThe app has a live registration and can place and take calls.
  • —No registration. The app is offline, or connected but not registered yet.
 PBX line

The server's own registration with the PBX on this client's behalf, when the server is in lines mode.

  • registeredThe PBX accepted the line. The server refreshes it before it expires.
  • pendingThe first registration has not been sent yet.
  • retryingThe last registration failed for a reason that may pass: the PBX is down, the network is out, or it answered with a server error. The server keeps trying.
  • refusedThe PBX rejected the credential or does not know the line. Retrying cannot fix it, so the line stays down until its credential is changed.
  • storedA line is configured but the server is not registering it: the server is in trunk mode, or the client is revoked.
  • —No line is configured for this client.
 State

Where the client is in its life, and whether it is on a call.

  • EnrolledA phone has claimed this client's credential and can sign in.
  • Not enrolledNo phone has claimed a credential yet. Make an enrolment code and enter it on the phone.
  • On a callA call is in progress. The time beside it is how long the call has been up.
  • RevokedThe credential has been cancelled. The phone can no longer connect, and its PBX line is not registered.
  • code valid until…An enrolment code is outstanding and expires at that time.
